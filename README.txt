MINECRAFT PLAYER PROFILE — EDITABLE WEBSITE

WHAT'S NEW:
- Click EDIT PROFILE on the website.
- Change username, profile ID, UUID, public account label, version, server details and social links.
- Upload your own Minecraft skin PNG from the website editor.
- Save changes; the page updates immediately.
- The editor stores changes in that browser/device using localStorage.

IMPORTANT ABOUT SAVING:
This is a static free-hosted website. Without a backend/database, edits are saved only in the browser/device where they are made. They will not automatically appear for other visitors or on your other devices.
To publish updated public details for everyone, edit the PROFILE object in script.js and redeploy the files, or later connect a database/admin system.
The uploaded skin saved through the editor is also local to that browser. For a globally shared skin, put the PNG in assets/skin.png and redeploy.

SETUP:
1) Upload all project files to a public GitHub repository.
2) Add your skin as assets/skin.png (optional; can also upload locally through Edit Profile).
3) GitHub repository Settings > Pages > Deploy from a branch > main > /(root) > Save.
4) Open the published GitHub Pages URL.

SAFETY:
Never publish Microsoft passwords, recovery codes, session tokens, or private sign-in information.
The server address is displayed as text only; this starter does not check live status/player count.
3D viewer and fonts load from public CDNs, so internet is required.
